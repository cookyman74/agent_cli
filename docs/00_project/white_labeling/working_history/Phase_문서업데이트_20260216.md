## 1. 작업 개요

Phase 1~3에서 프로덕션 코드의 `.gemini` -> `.didim` 전환이 완료되었으나, 사용자
대면 문서 32+ 파일에 `.gemini` 경로 참조가 잔존. 코드 현실에 맞게 문서를 동기화.

### 변환 범위

| 항목                             | 변환 규칙                                                                   |
| -------------------------------- | --------------------------------------------------------------------------- |
| `~/.gemini/`                     | `~/.didim/`                                                                 |
| `.gemini/` (디렉토리)            | `.didim/`                                                                   |
| `.geminiignore`                  | `.didimignore`                                                              |
| `gemini-extension.json`          | `didim-extension.json`                                                      |
| `.gemini-extension-install.json` | `.didim-extension-install.json`                                             |
| `GEMINI.md` (단독 기본값)        | `AGENTS.md`                                                                 |
| `gemini` (CLI 명령어)            | `didim`                                                                     |
| 내부 링크 slug                   | 리네임 반영 (`gemini-ignore` -> `didim-ignore`, `gemini-md` -> `agents-md`) |

### 변환 제외 대상

- "Gemini CLI" 프로덕트명, "Gemini" 모델명
- `GEMINI_API_KEY`, `GOOGLE_API_KEY`, `GEMINI_SANDBOX` 등 환경변수
- 외부 URL (geminicli.com, github.com/google-gemini 등)
- `gemini-cli` 프로젝트/레포명
- changelogs (역사적 기록)
- `docs/00_project/` 내부 프로젝트 문서
- 시스템 경로: `/Library/Application Support/GeminiCli/`, `/etc/gemini-cli/`
- `GEMINI.md` fallback 배열 내 참조 (예:
  `["AGENTS.md", "CONTEXT.md", "GEMINI.md"]`)

## 4. 특수 케이스 처리

### 4.1 `gemini` CLI vs "Gemini" 프로덕트명

- 코드블록/백틱 내 `gemini --flag`, `gemini extensions` 등 → `didim` 변환
- "Gemini CLI", "Gemini model" 등 프로덕트 참조 → 유지

### 4.2 `GEMINI.md` 배열 참조

- `["AGENTS.md", "CONTEXT.md", "GEMINI.md"]` fallback 배열 → `GEMINI.md` 유지
- 단독 기본값 참조 → `AGENTS.md` 변환

### 4.3 환경변수

- `GEMINI_SYSTEM_MD`, `GEMINI_PROJECT_DIR`, `GEMINI_API_KEY` 등 모두 유지 (변환
  제외)
- `GEMINI_SANDBOX=true didim` 형태의 env 접두사 CLI 명령어 → `didim` 부분만 변환

### 4.4 내부 링크 + sidebar.json

- `./gemini-md.md` -> `./agents-md.md`
- `./gemini-ignore.md` -> `./didim-ignore.md`
- sidebar.json slug/label 동기화 완료
