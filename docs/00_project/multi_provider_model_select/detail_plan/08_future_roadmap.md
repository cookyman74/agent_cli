# 08. 향후 확장 로드맵

## 11. 향후 확장 가능성

1. **모델 자동 업데이트**: API에서 사용 가능한 모델 목록을 동적으로 가져오기
2. **모델별 config**: 프로바이더-모델 조합별 temperature/maxTokens 기본값
3. **DidimAIStudio 시나리오 모델**: 향후 DidimAIStudio 연동 시 시나리오 모델
   목록 추가
4. **모델 북마크**: 자주 쓰는 모델을 즐겨찾기로 등록
5. **useAuth 리팩토링**: env 자동감지 경로에서도 `setSelectedProvider()`
   호출하여 상태 일관성 확보 (근본적 해결)
6. **모델 접근 제어**: API 키 플랜에 따라 사용 가능한 모델 필터링 (e.g., Free
   티어에서 o3 비활성)
