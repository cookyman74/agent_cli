- npm install -g @google/gemini-cli@latest
+ npm install -g @didim/agent-cli@latest

+ didim-agent-cli-{ver}.tgz

# ESLint self-import 방지
- name: '@google/gemini-cli'
+ name: '@didim/agent-cli'

## 5. 교훈 (Lessons Learned)

1. **`replace_all` 부분 문자열 주의**: `@google/gemini-cli` 치환 시
   `@didim/agent-cli-core` import도 변경됨. 접미사 포함
   패턴(`@google/gemini-cli@`) 사용이 안전.
2. **npm workspace명 변경 영향**: `package.json` name 변경 후 모든 `-w` 명령에서
   새 이름 사용 필요.
3. **publishConfig 필수**: scoped npm 패키지(`@didim/...`)는
   `"access": "public"` 설정 필요.
4. **문서 변경 시 필터링**: `gemini-cli-core`, `gemini-cli-a2a` 참조를
   보존하면서 CLI 전용 참조만 변경.
